# The Perceptron Machine — Figure Prompt Atlas

**Book:** *The Perceptron Machine: Threshold Logic, Adaptive Hardware, and the Architecture of IC 616*  
**Author:** Adarsh Keshri  
**Edition:** Research Edition 2026

This atlas contains the complete prompt set for the book. Generate conceptual composition first, then rebuild all labels, equations, arrows, and data charts manually in a vector editor. Technical labels produced inside an image model must not be trusted without correction.

## Global visual system

- White or dark graphite backgrounds only when specified; most interior figures use white.
- Conventional exact logic: grey/black. Fixed threshold logic: cobalt blue. Adaptive logic: teal. Faults/attacks: red dashed.
- Engineering line art, high legibility, restrained palette, generous whitespace.
- No biological brains, humanoid robots, neon cyberpunk boards, decorative code, fake microtext, or physically impossible chip structures.
- Prefer SVG/PDF for diagrams and 300-dpi or higher for rendered cover/device scenes.
- Regenerate composition as needed, but manually typeset every final label.
